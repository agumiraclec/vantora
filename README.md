## 🌟 Key Features

*   **Forgery-Proof Attendance:** Cryptographically signed QR cards prevent unauthorized check-ins.
*   **Instant Parent Alerts:** Automated emails with GPS location links sent the second a child arrives or leaves.
*   **Offline-First Architecture:** Never miss a scan. The app works flawlessly without internet and syncs in the background.
*   **Real-Time Dashboards:** Live oversight of check-ins, check-outs, absentees, and active visitors.
*   **Integrated Staff Comms:** Secure text, image sharing, and voice/video calls built directly into the app.

## 🔒 Security & Privacy

Vantora is built with an enterprise-security mindset. All PINs are salted and hashed, admin access requires 2-Factor Authentication (2FA), and all local offline data is heavily encrypted. School data is strictly isolated—School A can never see School B's data.
